# Software Dependencies

This inventory is based on the supplied source files. It may omit indirect dependencies, data services or external commands. Original software versions are not pinned.

## Stata

Stata is required. Check that your version supports the modelling commands used. The examples use `stset`, `sts`, `stcox` and `stcrreg`; `coefplot` is an additional command. The original script may also require commands such as `fre`.

See [the project README](README.md) for expected inputs and [reproducibility notes](../../REPRODUCTIBILITE.md) for execution limits.
